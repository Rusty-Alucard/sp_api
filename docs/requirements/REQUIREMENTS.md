# SP API プロジェクト要件定義書

## 1. プロジェクト概要

### 1.1 システム名
SP API (Soccer Prediction API) - サッカープレディクションシステム

### 1.2 プロジェクト目的
レガシーシステム（PHP + S2Container）からモダンなGo + GraphQL APIシステムへの移行により、以下の目的を達成する：

- **技術的負債の解消**: レガシー技術スタックからの脱却
- **スケーラビリティの向上**: マイクロサービス指向のアーキテクチャ
- **開発効率の向上**: モダンな開発ツールとプラクティス
- **保守性の向上**: ドメイン駆動設計（DDD）による保守性向上
- **APIファースト**: GraphQL APIによる柔軟なデータ提供

### 1.3 システム概要
- **新システム**: Go + GraphQL + PostgreSQL + Redis + Elasticsearch
- **アーキテクチャ**: ドメイン駆動設計（DDD）ベースのClean Architecture
- **API**: GraphQL API（REST APIも併用）
- **データベース**: PostgreSQL（メイン）、Redis（キャッシュ）、Elasticsearch（検索）
- **外部連携**: FIFA API、各種サッカー関連API

## 2. 機能要件

### 2.1 コア機能群

#### 2.1.1 ユーザー管理機能
**概要**: ユーザーの登録、認証、プロフィール管理

**機能詳細**:
- **ユーザー登録**: メールアドレス、パスワード、基本情報での登録
- **認証**: JWT ベースの認証システム
- **プロフィール管理**: ユーザー情報の編集、アバター設定
- **パスワード管理**: パスワード変更、リセット機能
- **アカウント管理**: アカウント削除、一時停止

**API エンドポイント**:
```graphql
type Mutation {
  registerUser(input: RegisterUserInput!): User!
  loginUser(input: LoginInput!): AuthPayload!
  updateProfile(input: UpdateProfileInput!): User!
  changePassword(input: ChangePasswordInput!): Boolean!
  resetPassword(input: ResetPasswordInput!): Boolean!
}

type Query {
  me: User
  user(id: ID!): User
  users(filter: UserFilter): [User!]!
}
```

#### 2.1.2 大会・試合管理機能
**概要**: サッカー大会と試合情報の管理

**機能詳細**:
- **大会管理**: 大会情報の登録、編集、削除
- **試合管理**: 試合情報の登録、結果更新
- **リアルタイム更新**: WebSocket による試合結果のリアルタイム配信
- **スケジュール管理**: 試合スケジュールの管理
- **統計情報**: 試合統計、チーム統計の提供

**API エンドポイント**:
```graphql
type Query {
  events: [Event!]!
  event(id: ID!): Event
  matches(eventId: ID!): [Match!]!
  match(id: ID!): Match
  teams: [Team!]!
  team(id: ID!): Team
}

type Mutation {
  createEvent(input: CreateEventInput!): Event!
  updateEvent(id: ID!, input: UpdateEventInput!): Event!
  createMatch(input: CreateMatchInput!): Match!
  updateMatchResult(id: ID!, input: UpdateMatchResultInput!): Match!
}
```

#### 2.1.3 予想機能
**概要**: 試合結果、スコア、優勝チームの予想システム

**機能詳細**:
- **試合結果予想**: ホーム勝利、アウェイ勝利、引き分けの予想
- **スコア予想**: 正確なスコアの予想
- **優勝予想**: 大会優勝チームの予想
- **予想履歴**: 過去の予想結果の確認
- **予想制限**: 試合開始前までの予想制限

**API エンドポイント**:
```graphql
type Mutation {
  createPrediction(input: CreatePredictionInput!): Prediction!
  updatePrediction(id: ID!, input: UpdatePredictionInput!): Prediction!
  deletePrediction(id: ID!): Boolean!
}

type Query {
  predictions(userId: ID, matchId: ID): [Prediction!]!
  prediction(id: ID!): Prediction
  predictionStats(userId: ID!): PredictionStats!
}
```
