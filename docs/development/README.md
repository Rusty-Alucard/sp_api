## 開発環境

### 必要なツール
- **Go**: 1.25.1以上
- **Docker**: 最新版
- **Docker Compose**: 最新版
- **Git**: 最新版
- **golangci-lint**: コード品質チェック
- **gosec**: セキュリティチェック

### 開発環境のセットアップ
```bash
# リポジトリのクローン
git clone <repository-url>
cd sp_api

# 依存関係のインストール
go mod download

# 開発ツールのインストール
make install-tools

# 開発環境の起動
docker-compose up -d

# テストの実行
make test
```

## コーディング規約

### Go言語
- **フォーマット**: `go fmt`を使用
- **インポート**: `goimports`を使用
- **命名規則**: Goの慣例に従う
- **コメント**: 公開関数には必ずコメントを記述

### テスト
- **テストファイル**: `*_test.go`の形式
- **テスト関数**: `Test*`の形式
- **カバレッジ**: 80%以上を維持

### ドキュメント
- **README**: 各パッケージにREADMEを作成
- **コメント**: 公開APIには必ずコメントを記述
- **例**: 使用例を含める

## 品質管理

### 静的解析
- **golangci-lint**: コード品質チェック
- **gosec**: セキュリティチェック
- **go vet**: 基本的な問題検出

### テスト
- **単体テスト**: 各関数・メソッドのテスト
- **統合テスト**: 外部依存との統合テスト
- **E2Eテスト**: エンドツーエンドのテスト

### コードレビュー
- **プルリクエスト**: すべての変更はPRでレビュー
- **承認**: 最低2名の承認が必要
- **チェックリスト**: 実装チェックリストに基づく確認

## トラブルシューティング

### よくある問題

**問題**: テストが失敗する  
**原因**: 依存関係の不整合  
**解決法**: `go mod tidy`を実行

**問題**: 静的解析でエラーが出る  
**原因**: コーディング規約に違反  
**解決法**: `golangci-lint`の指摘に従って修正

**問題**: Dockerコンテナが起動しない  
**原因**: ポートの競合やリソース不足  
**解決法**: `docker-compose down`で停止後、再起動
